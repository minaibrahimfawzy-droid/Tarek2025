# نظام متابعة الطرق والقطاعات — Windows

## النسخة
**1.0.0**

هذا المشروع يحوّل ملف HTML الأصلي إلى تطبيق Windows باستخدام Electron، مع إعداد جاهز لإنشاء Installer فقط.

## تشغيل المشروع على Windows

ثبّت Node.js ثم افتح Command Prompt داخل مجلد المشروع:

```bat
npm install
npm start
```

## إنشاء نسخة العميل

```bat
npm run dist
```

سيتم إنشاء **Installer فقط** بصيغة `.exe` داخل مجلد `dist`.

## التحديثات عبر GitHub

ملف `package.json` يحتوي على إعداد GitHub Releases. قبل أول نشر غيّر:

```json
"owner": "minaibrahimfawzy-droid",
"repo": "Tarek2025"
```

إلى اسم حسابك واسم المستودع الحقيقي.

عند إصدار تحديث:
1. عدّل البرنامج.
2. غيّر رقم `version` في `package.json`، مثال: `1.0.0` → `1.1.0`.
3. نفّذ `npm run dist`.
4. ارفع ملفات الإصدار إلى GitHub Release.

> ملاحظة: كود الفحص والتنزيل التلقائي للتحديث موجود بالفعل. يلزم فقط وضع اسم حساب GitHub واسم المستودع الحقيقيين في `package.json` قبل بناء نسخة العميل النهائية. عند عدم وجود إنترنت أو تعذر الوصول إلى GitHub يستمر البرنامج في العمل طبيعيًا.

## البيانات

التطبيق الأصلي يعتمد على `localStorage` داخل HTML. لا يتم حذف بيانات التطبيق عند إزالة التثبيت في إعداد NSIS الحالي (`deleteAppDataOnUninstall: false`). كما أن النظام الأصلي يحتوي على النسخ الاحتياطي والاستعادة JSON.

## مهم

لا تعدّل ملف `.exe` مباشرة. احتفظ بهذا المشروع كمصدر البرنامج، وكل تحديث يصدر من نفس المشروع برقم إصدار جديد.
